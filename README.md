# Punto Duerme

El juego del pueblo que duerme, de [Punto Studio](https://puntostudio.es/): cada uno con su móvil y un móvil que hace de narrador con voz. Hermano de [Punto Falso](https://puntostudio.es/punto-falso/) y [Punto Ciego](https://puntostudio.es/punto-ciego/).

Beta: https://puntostudio.es/punto-duerme/beta/

Reglas, estructura y cómo se sincronizan los móviles: ver [CLAUDE.md](CLAUDE.md).
